# tracegauge 0.16.0: release notes (long form)

The short entry is in [CHANGELOG.md](../../CHANGELOG.md). This page holds the migration detail and the
checks behind it, in the same shape as [0.15.0.md](0.15.0.md). Status: released as 0.16.0 on 2026-10-17.

Every figure here carries the command that reproduces it, or is labelled as the maintainer's unpublished
local measurement. This release has no new measurement of that second kind.

## BREAKING: read before upgrading

1. **Rename: `tes` becomes `tracegauge` for the import package, the command and the environment variables.**
   The PyPI distribution was already called `tracegauge`. The old names keep working until 0.18 and print a
   deprecation notice; the store directory `~/.tes/` does not move. The table of old and new names, the
   three output strings that changed (`--version`, one sentence of the JSON field `cost_domain_of_validity`, the
   report banner) and the timeline are in [MIGRATING_FROM_TES.md](../MIGRATING_FROM_TES.md). Scores, JSON field
   names and types, and exit codes are unchanged.
2. **Licence: Apache-2.0 from 0.16.0.** Releases up to 0.15.0 were AGPL-3.0-only, apart from three files that
   carried a dual "AGPL-3.0-only OR Apache-2.0" header (`tes/cost.py`, `tes/_digest.py`, `tes/discovery.py`);
   they stay under those terms for anyone who received them. `LICENSE` holds the Apache-2.0 text and `NOTICE`
   records the boundary and the third-party material (fonts under SIL OFL 1.1) that keeps its own licence.
   Contributions are accepted under Apache-2.0 with a Developer Certificate of Origin sign-off
   ([CONTRIBUTING.md](../../CONTRIBUTING.md)).

## Added

- **Cache-churn detector**, [CACHE_CHURN.md](../CACHE_CHURN.md): `tracegauge.cache_churn`, the CACHE CHURN section of
  `tracegauge score`, the `cache_churn` object of `tracegauge score --json`, and a card on the dashboard's session
  page. Real output on a synthetic session with three planted re-writes is in the README, regenerated by
  `python scripts/gen_readme_demo.py` and pinned by `tests/test_readme_demo.py`.
- `tgauge` alias, `TRACEGAUGE_*` variables, `python -m tracegauge`.
- DCO sign-off check (`scripts/check_dco.py`, CI job `dco`) and secret scan (gitleaks hook, CI job `secret-scan`).
- [METHODOLOGY.md](../METHODOLOGY.md) and [COMMANDS.md](../COMMANDS.md): the README's methodology, caveats and
  long-form usage, moved unchanged so the README can lead with what the tool finds.
- [RENAME_REPO.md](../RENAME_REPO.md): the repository owner's ordered steps for renaming the repository.

## Changed

- README restructured (pitch, recording, install, what it finds, commands, supported agents, methodology).
- Waste detectors pinned by sha256 as well as by `git diff`.
- Fonts: OFL texts shipped; IBM Plex subsets renamed `TG Sans` / `TG Mono` (the name "Plex" is reserved).
- Dataset attribution and licence labels corrected in `DATA_SOURCES.md`.
- Task classification no longer special-cases one private session id.

## Removed

Third-party and derived material this release no longer redistributes (SWE-Gym corpus entries, nebius trajectory text,
SWE-chat-derived per-session waste signals, free-text judge commentary), and PR-evidence screenshots (11 images that
shipped in 0.15.0; 6 more added after 0.15.0 were also removed) that showed local paths or real session ids. See the CHANGELOG entry and `DATA_SOURCES.md`.

## Known gaps

- The removed screenshots (11 from 0.15.0, 17 counting those added after it) were not re-captured; nothing in the README or the docs references them.
- Links still use the old repository name until the owner renames the repository
  ([RENAME_REPO.md](../RENAME_REPO.md)).
- The figures the research reports derived from removed data cannot be re-derived from a clone.
